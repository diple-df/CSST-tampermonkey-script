# Custom Search System Tabs (CSST)

> Tampermonkey-скрипт для настройки панели вкладок поиска в Google, Яндексе, Bing, DuckDuckGo, Ecosia, Startpage, Brave Search и Qwant.  
> Скрывайте ненужные вкладки, переименовывайте их, перенаправляйте на другие сервисы и добавляйте свои кнопки прямо в панель навигации поисковика.
>
> **Автор:** diple_df x claude · **Версия:** 1.3.1

---

## Установка

### Шаг 1 — Установите менеджер пользовательских скриптов

Скрипт работает через расширение-менеджер для браузера. Поддерживаются:

| Расширение | Chrome | Firefox | Edge |
|---|---|---|---|
| **Tampermonkey** (рекомендуется) | ✓ | ✓ | ✓ |
| Violentmonkey | ✓ | ✓ | ✓ |
| Greasemonkey | — | ✓ | — |

Установите расширение из официального магазина вашего браузера.

### Шаг 2 — Установите скрипт

**Вариант А — установка в один клик (рекомендуется):**

1. Нажмите на ссылку автоматической установки: **[Установить Custom Search System Tabs](https://raw.githubusercontent.com/diple-df/CSST-tampermonkey-script/main/csst_tmprmnk.user.js)**
2. Tampermonkey автоматически перехватит файл и откроет страницу установки
3. Нажмите **Установить**

**Вариант Б — вручную:**

1. Скопируйте содержимое файла `csst_tmprmnk.user.js`
2. Откройте Tampermonkey → **Create a new script**
3. Вставьте код и нажмите **Сохранить** (`Ctrl+S`)

### Шаг 3 — Откройте любой поисковик

Перейдите на любой поддерживаемый поисковик, введите запрос — в строке вкладок появится кнопка настроек (≡).

Размер и выравнивание кнопки подстраиваются под строку вкладок каждого движка: у Bing она меньше (низкий scopebar), у Google и Яндексa — круглее и крупнее, и так далее.

> Проверка «вживую» означает прогон в браузере на настоящей странице. Настройки хранятся **отдельно для каждой поисковой системы** — изменения в Google не влияют на Яндекс.

## Основные функции

### Кнопка ≡ и быстрый трей

В строке вкладок поисковика появляется кнопка ≡. При наведении (или фокусе с клавиатуры) под ней всплывает компактный трей **всего с двумя действиями**:

1. **Скрыть/показать текущую вкладку** — иконка меняется в зависимости от состояния;
2. **Открыть все настройки** — полная панель.

Всё, что требует ввода текста (переименование, редирект), намеренно живёт только в раскрытой панели. Трей плавающий (`position: fixed`), поэтому не растягивает строку вкладок и не обрезается её `overflow`.

На кнопке показывается **счётчик скрытых вкладок** — состояние видно без открытия панели.

### Скрыть вкладку

Любую стандартную вкладку поисковика можно полностью убрать из панели. Скрипт прячет и саму ссылку, и её обёртку (`<li>`, `<div>`), чтобы не оставалось пустых мест.

Вкладки, скрытые самим поисковиком (например, «Товары» у Яндекса), скрипт не трогает — открываются только те, которые скрыл именно он.

### Переименовать вкладку

Вы можете задать любое название для любой вкладки. Подпись меняется сразу в панели без перезагрузки страницы. Если вы очищаете поле — скрипт возвращает оригинальную подпись поисковика.

### Перенаправить вкладку на другой сервис

Вместо стандартного раздела поисковика вкладка может открывать любой другой сайт. Например:

- Вкладка **Видео** в DuckDuckGo → открывает **YouTube** с тем же запросом
- Вкладка **Картинки** в Яндексе → открывает **Google Images**
- Вкладка **Карты** в Google → открывает **OpenStreetMap**

В поле URL можно использовать `{query}` — скрипт автоматически подставит текущий поисковый запрос. Если в поле нет `{query}`, панель подсвечивает его красным и объясняет, чего не хватает.

### Добавить кастомную кнопку

Помимо стандартных вкладок, можно добавить любое количество собственных кнопок прямо в строку навигации поисковика. Кнопки поддерживают `{query}` и отображаются в том же стиле, что и родные вкладки.

Примеры использования:
- Кнопка «GitHub» → `https://github.com/search?q={query}`
- Кнопка «Amazon» → `https://www.amazon.com/s?k={query}`
- Кнопка «Translate» → `https://translate.google.com/?text={query}&sl=auto&tl=ru`

## Панель настроек

Панель открывается кнопкой ≡ (или пунктом меню Tampermonkey) и содержит:

- **Фильтр** по названию вкладки с кнопкой очистки, счётчиком найденного и понятным пустым состоянием;
- **Список вкладок поисковика** с группировкой и закреплённым заголовком раздела;
- **Статус-чипы** у каждой строки: `скрыта`, `имя`, `редирект` — видно, что именно изменено, без раскрытия строки;
- **Раскрытие строки** (шеврон) — поля «Подпись», «Быстрый выбор сервиса», «URL редиректа»;
- **Свои кнопки** отдельным разделом с удалением в один клик;
- **Безопасный режим** и **язык интерфейса** внизу списка;
- **Экспорт/импорт** настроек в JSON и **сброс** в два шага.

### Перестановка вкладок

Порядок вкладок в панели можно менять перетаскиванием (за иконку-«гриф» слева) или клавишами `Alt`+`↑`/`↓`. Порядок сохраняется и применяется к строке вкладок поисковика. Пока вы ничего не перетаскивали, порядок остаётся родным для движка.

### Безопасный режим

Если поисковик сменил вёрстку и скрипт начал мешать — включите «Безопасный режим (только кнопка)». Тогда скрипт не трогает вкладки вообще (не скрывает, не переименовывает, не перенаправляет, не переставляет), но кнопка ≡ и панель продолжают работать.

### Язык интерфейса

Язык определяется автоматически по атрибуту `lang` страницы, но его можно зафиксировать вручную в панели — выбор сохраняется и больше не «прыгает» на многоязычных страницах. Для арабского панель переключается в режим справа-налево (`dir="rtl"`): зеркалятся отступы, выравнивание и позиция панели.

## Как пользоваться

1. Откройте любой поддерживаемый поисковик и введите запрос
2. В панели навигационных вкладок найдите кнопку **≡** — она добавляется скриптом
3. Нажмите на неё — откроется панель настроек рядом с кнопкой
4. В секции **Вкладки поисковика** настройте каждую вкладку:
   - Нажмите иконку глаза, чтобы скрыть или показать вкладку
   - Раскройте строку шевроном и измените **Подпись**
   - Выберите готовый сервис из списка или вручную введите **URL редиректа**
5. В секции **Свои кнопки** нажмите **Добавить кнопку**, чтобы вставить свою ссылку
6. Изменения применяются мгновенно; панель закрывается по `Esc`, клику вне её или кнопке закрытия
7. Кнопка **Сброс** требует подтверждения вторым нажатием и возвращает все настройки к исходным

> Если кнопка **≡** не появилась в строке вкладок, откройте настройки через меню Tampermonkey → скрипт → **Настроить вкладки поиска**.

### Если вкладки не нашлись

При смене вёрстки поисковика список может оказаться пустым. В этом случае панель показывает не голый текст, а кнопку **«Показать все известные вкладки»** — настройки остаются доступными, даже если автоопределение сломалось.

Скрипт также проверяет не только домен, но и «похожесть» страницы: если контейнер вкладок не находится несколько раз подряд, он тихо не вмешивается, вместо того чтобы вешать кнопку в случайное место.

## Шаблон {query}

В любом URL (редиректе или кастомной кнопке) можно использовать `{query}` — скрипт заменит его на текущий поисковый запрос, закодированный для URL.

**Примеры:**

```
https://www.youtube.com/results?search_query={query}
https://github.com/search?q={query}&type=repositories
https://www.amazon.com/s?k={query}
https://translate.google.com/?text={query}&sl=auto&tl=ru
```

При вводе запроса `смешные коты` ссылка `https://www.youtube.com/results?search_query={query}` превратится в `https://www.youtube.com/results?search_query=%D1%81%D0%BC%D0%B5%D1%88%D0%BD%D1%8B%D0%B5%20%D0%BA%D0%BE%D1%82%D1%8B`.

## Приватность

В хранилище (`GM_setValue`) попадают **только**:

- подписи вкладок и кастомных кнопок;
- URL редиректов и кастомных кнопок (шаблон с `{query}`);
- флаги: `hidden` у вкладки, `safeMode`;
- порядок вкладок;
- выбранный язык интерфейса и версия схемы конфига.

**Поисковые запросы никогда не сохраняются.** `{query}` подставляется в момент клика или применения и живёт только в DOM. Скрипт не отправляет запросы на сторонние сервисы, кроме одной служебной проверки обновлений (см. ниже).

### Импорт и экспорт

Экспорт — обычный JSON, который можно скопировать или скачать файлом. Импорт **проверяется по схеме**: проверяются версия схемы и типы полей. Битый или чужой JSON отклоняется с понятным сообщением и не попадает в настройки.

### Проверка обновлений

Кроме пассивного механизма обновления Tampermonkey (`@updateURL`/`@downloadURL`), скрипт раз в сутки проверяет свою актуальную версию: в простое (`requestIdleCallback`) скачивает собственный raw-файл с `raw.githubusercontent.com` и сравнивает номер версии. Запрос идёт не чаще одного раза в сутки, таймаут — 15 секунд, любая ошибка гасится молча. Если доступна новая версия, один раз на версию показывается баннер со ссылкой на файл.

Проверку можно запустить вручную: меню Tampermonkey → **Проверить обновления**.

## Техническая информация

### Права доступа (Grants)

| Право | Зачем |
|---|---|
| `GM_getValue` | Чтение сохранённых настроек |
| `GM_setValue` | Сохранение настроек |
| `GM_addStyle` | Добавление стилей кнопки в строке вкладок |
| `GM_registerMenuCommand` | Запасная точка открытия настроек через меню Tampermonkey |
| `GM_xmlhttpRequest` | Проверка обновлений (только `raw.githubusercontent.com`) |
| `@connect raw.githubusercontent.com`, `@connect github.com` | Разрешение для проверки обновлений |

### Как устроен скрипт

- Адаптеры поисковиков описаны **данными**: селекторы контейнера, обёртка, класс ссылки и declarative-карта классификации ссылок. Функция остаётся только там, где нужна настоящая логика.
- Контейнер вкладок ищется каскадом: селекторы движка → стабильный якорь → семантический `nav` → «самый густой кластер ссылок» → универсальная эвристика по форме строки вкладок. Каждый кандидат проверяется: он должен быть у верхней кромки страницы, не быть автокомплитом поисковой строки и содержать минимум две ссылки своего домена. Поэтому промах селектора не вешает кнопку в случайный `<ul>` и не бросает исключение, а каскад идёт дальше. Победившая стратегия запоминается на сессию, результат кешируется на проход.
- Изменения отслеживает один дебаунсенный `MutationObserver` (без `setInterval`) с защитой от повторного входа и «тихим окном» после собственных записей в DOM. Если страница перерисовывает строку вкладок и удаляет кнопку вместе с её обёрткой, скрипт возвращает её сам.
- Вкладка — не обязательно ссылка: у Startpage это `<button>` внутри формы, поэтому поддерживаются и кнопки-разделы, и ссылки.
- Для отладки в консоли доступен `window.__csstDiag`: `{ engine, strategy, selector, container, tabs }` — показывает, какая стратегия каскада победила и в какой узел вставлена кнопка. Ничего не сохраняет и никуда не отправляет.
- Панель живёт в Shadow DOM (`<csst-ui id="usc-ui-host">`): это защищает её от страничных скриптов, которые удаляют добавленные в light DOM элементы.
- Все иконки — встроенные SVG на `stroke="currentColor"`, без внешних ресурсов и веб-шрифтов.
